# 鐵與泥 1916

一款可在瀏覽器直接遊玩的單機 3D 第一次世界大戰風格 FPS。使用 Three.js + Rapier3D 打造，包含四兵種、16v16 AI、征服模式、坦克與吉普車，以及三張可選地圖。

## 線上遊玩

**https://davidlee-jojo.github.io/iron-mud-1916/**

> 建議使用桌面版 Chrome / Edge。第一次載入需要數秒生成地形與導航網格。
>
> 每次 push 到 `master` 分支時，GitHub Actions 會自動建置並部署到 GitHub Pages。

> 所有模型、貼圖、天空、粒子與音效都是程式化生成，沒有下載任何外部美術或音檔。

## 快速開始

### 需求

- Node.js 18 或更新版本
- 桌面版 Chrome / Edge（需要 WebGL2 與 WebAssembly）
- 不支援手機瀏覽器

### 安裝與啟動

```bash
npm install
npm run dev
```

開啟終端機顯示的網址（預設 `http://localhost:5173`）。

> Windows PowerShell 若出現「npm.ps1 無法載入」：
>
> ```powershell
> npm.cmd run dev
> ```
>
> 或放寬目前使用者的執行原則：
>
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

### 建置靜態版本

```bash
npm run build
npm run preview
```

建置結果在 `dist/`，可放到任何靜態網站空間。

| `W A S D` | 移動 |
| `Shift` | 衝刺 / 狙擊瞄準時閉氣 |
| `Ctrl` | 蹲下 |
| `Space` | 跳躍 |
| 滑鼠左鍵 | 開火 / 坦克主砲 / 吉普機槍 |
| 滑鼠右鍵 | 瞄準 / 坦克同軸機槍 |
| `R` | 換彈 |
| `1` / `2` | 切換主武器 / 副武器 |
| `G` | 手榴彈（工程兵為反載具地雷） |
| `F` | 兵種技能（突擊兵 AT 手榴彈、醫療兵醫療包、狙擊兵信號彈、工程兵維修） |

- 醫療兵按住 `E` 約 2 秒可復活倒地隊友。

- 進入載具後，滑鼠控制砲塔 / 機槍方向，`W S A D` 駕駛，`E` 下車。

## 遊戲內容

### 模式

- **征服模式**：3 個旗點 A / B / C，雙方各 400 票。
- 佔領旗點會使敵方持續扣票；擊殺與死亡也會影響票數。
- 15 分鐘上限，票數較高或先歸零的一方決定勝負。
- **16v16**：玩家加入協約國，該隊為 15 名 AI + 玩家；同盟國為 16 名 AI，合計 32 名士兵。

### AI 行為邏輯

- **小隊分工**：每隊 AI 分成四種小隊：
  - 中央小隊：固定爭奪/防守最靠近地圖中心的旗點。
  - 進攻小隊：優先攻擊外圍的非己方旗點。
  - 第二進攻小隊：負責另一個外圍旗點，避免所有人擠在同一處。
  - 防守小隊：優先守住己方最近的旗點。
- **感知**：每名 AI 以約 8Hz 更新，檢查最近 6 名敵人的視野與視線；被攻擊或聽到附近槍聲時會立刻記住來源方向並前往調查。
- **交戰**：發現敵人後會依兵種保持距離、射擊、側移；血量過低才撤退。
- **兵種行為**：醫療兵會治療與復活、工程兵會維修載具與佈雷、突擊兵會用 AT 手榴彈打載具、狙擊兵會打遠程並發射信號彈。
- **積極度**：AI 會主動推進旗點、對槍聲與攻擊做出反應，不再只被動等敵人上門。
- **地形通行**：戰壕沿線設有出入口坡道（地圖上可見的缺口），AI 前方被擋時會自動側移繞行；導航網格會偵測陡坡帶與道具頂面，路徑不會再帶 AI 撞牆卡死。

### 四兵種

| 兵種 | 主武器 | 技能 | 定位 |
|---|---|---|---|
| 突擊兵 | MP18 衝鋒槍 | 反載具手榴彈 | 近距壓制、反載具 |
| 醫療兵 | Selbstlader M1916 | 醫療包、復活 | 治療與維持戰線 |
| 工程兵 | BAR M1918 | 維修扳手、反載具地雷 | 修載具、封鎖路線 |
| 狙擊兵 | Gewehr 98（4 倍鏡） | 信號彈 | 遠距擊殺、偵察標記 |

### 載具

- **Mark V 坦克**：車體移動、旋轉砲塔、主砲（4.2 秒裝填、濺射傷害）、同軸機槍、正面/側面/背面裝甲倍率、冒煙與起火、被摧毀後 30 秒重生。
- **砲塔與車體獨立**：滑鼠只控制砲塔（可 360 度旋轉，車體轉向時砲塔會保持原瞄準方位），`W/S` 沿車體前後、`A/D` 旋轉車體；HUD 下方有車體方向指示器，方便對照車頭與視線。
- **強化的地形能力**：坦克上坡會自動補償推力與貼坡速度，遇到沙包、彈坑緣、戰壕階梯等低矮障礙會直接碾過去；外觀會貼合地形俯仰傾斜。
- **偵察吉普**：高速、四輪、可旋轉車載機槍、可被反載具武器摧毀。
- 工程兵可維修；突擊兵 AT 手榴彈、工程兵地雷、坦克砲彈都能重創載具。
- 高速載具會撞傷步兵。

### 三張地圖

| 地圖 | 天氣 / 時間 | 特色 |
|---|---|---|
| **灰燼谷** | 黎明薄霧 | 北側村落與教堂、中央彈坑、南側戰壕網 |
| **黃昏嶺** | 黃昏暖陽 | 山頂石堡、鐵路車站、葡萄園、台地與高低差 |
| **陰雨渡口** | 陰雨藍灰 | 河流、斷橋、淺灘、磨坊、補給倉庫、半淹戰壕 |

- 主選單可自由選擇地圖。
- 每張地圖都有獨立地形、佈局、旗點、出生點、載具點、天氣與環境音。
- 地圖切換會完整卸載上一張圖的幾何、碰撞體、導航網格與物件池。

## 調整與擴充

- **遊戲節奏 / 票數 / AI 難度**：`src/config/game.js`
- **武器傷害、射速、後座力、擴散**：`src/config/weapons.js`
- **兵種武器與技能**：`src/config/classes.js`
- **地圖地形、旗點、出生點、載具點、天氣**：`src/config/maps.js`
- **地圖佈局**：`src/world/maps/*.js` 與 `src/world/Builders.js`
- **AI 行為**：`src/entities/Bot.js`
- **載具手感**：`src/entities/Vehicle.js`（加速度、最高速、轉向）
- **畫質與效能**：遊戲內設定，或 `src/systems/PostFX.js`、`src/world/Weather.js`
- **玩家設定**保存在 `localStorage` 的 `ironmud1916_settings`。

> 程式碼中的關鍵演算法（A*、載具裝甲、命中判定、旗點控制、物件池）都有中文註解。

## 效能與畫質

- 設定中有 **亮度滑桿**（0.70–1.80），預設 1.40；覺得地面太暗或太亮時可直接調整，會即時套用到畫面並保存。
- 畫質分為 **低 / 中 / 高**：
  - 低：關閉泛光與 SMAA、1x pixel ratio、1024 陰影、較少雨量。
  - 中：泛光、SMAA、1.25x pixel ratio、2048 陰影。
  - 高：較強泛光、1.6x pixel ratio、4096 陰影、較多雨量。
- 目標為 1080p 中等畫質 60fps；16v16 與陰雨渡口若較吃效能可切到「低」。
- 若幀率不足，優先降低畫質與關閉 FPS 顯示以外的效果。
- 靜態地圖幾何會合批；沙袋、草、樹使用 InstancedMesh / 合併網格降低 draw call。

## 疑難排解

- **點擊後沒有鎖定滑鼠**：部署後點擊畫面任一處即可重新要求 Pointer Lock。
- **畫面全黑 / 初始化失敗**：開啟瀏覽器主控台查看錯誤；確認瀏覽器支援 WebGL2 與 WebAssembly。
- **載入卡在導航網格**：第一次載入會掃描約 4 萬個格子，通常數秒內完成；若超過 30 秒請重新整理。
- **沒有聲音**：瀏覽器要求先有使用者互動才能播放音效，點擊選單或畫面即可。
- **FPS 很低**：切到低畫質；關閉其他佔用 GPU 的分頁；確認使用硬體加速。
- **PowerShell 無法執行 npm**：使用 `npm.cmd` 或調整執行原則（見上方）。

## 已知限制

- 僅單人對 AI，沒有線上多人與手機支援。
- 載具為街機物理，不是硬核模擬；坦克與吉普車不會翻覆。
- AI 會導航、佔點、交戰、治療、復活與維修，但不如真人靈活。
- 程序化音效為風格化合成音，不是真實錄音。
- 首次載入需生成地形、佈局與導航網格，會有數秒載入時間。
- 平衡、手感與 AI 難度可能需要依實際遊玩再微調。
